How to download:
Click the green button that looks like this: < > Code

Open your Folder app and select the file called retro-bowl-main.zip
Click on the Index.html File.
DO NOT RENAME THE FILES
Index is where your game will be with the save file feature, and the retro-bowl.html is the game the index file uses.
You need both files.
